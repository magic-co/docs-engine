# Agent instructions

This repo builds docs-engine. It is a public repo.

- Write all prose in ASD-STE100 Simplified Technical English. Use short sentences and the active voice.
- Do not use the em-dash character.
- Use only made-up examples, such as a small coffee roastery. Do not name a real company, client or business process.
- Write a code comment only for a reason that the code cannot show.
- Before you commit, run `npm run typecheck`, `npm test` and `npm run lint:docs`.
- Keep the pstack skills in `.claude/skills/`. Do not edit them by hand.

See [the agent notes](docs/agents/README.md) for more.
